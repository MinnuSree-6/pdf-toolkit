PDF Toolkit
Real PDF tools, free to use, right in your browser. No installs, no accounts needed for the core tools.
🔗 Live site: https://pdf-toolkit-phi.vercel.app
What works right now (runs entirely in your browser)
Merge PDF
Split PDF
Organize PDF (reorder / remove pages)
Page Numbers
Rotate PDF
Crop PDF
Watermark
Compress PDF
PDF to JPG / JPG to PDF
Sign PDF (draw your signature)
Edit PDF (add text)
Unlock PDF (remove a known password)
PDF to Markdown
Coming soon (need a backend server)
These tools show up in the app but need a small server to actually run:
OCR PDF, Compare PDF, Redact PDF, PDF to PDF/A, Repair PDF, HTML to PDF, Protect PDF, PDF Forms, AI Summarizer, Translate PDF, Word/PowerPoint/Excel ⇄ PDF conversions.
To enable these, deploy your own backend and set its URL using the ⚙️ icon in the top right of the site.
Tech used
pdf-lib — create/edit PDFs in the browser
pdf.js — render and read PDFs
JSZip — package multi-file downloads as ZIP
Deployed on Vercel
Running locally
Just open index.html in any modern browser — no build step needed.
